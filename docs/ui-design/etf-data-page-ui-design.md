# ETF 数据页（/etf-data）UI 设计

> 范围：旧版 Web 应用（`frontend/` + `backend/`，`http://localhost:8901`）。
> 参考：现有「个股数据」页 `/stock-data`（`stock-data-page-ui-design.md`）与「股票筛选」页（`stock-screener-page-design.md`）。
> 目标：新增独立的 ETF 数据视图，视觉与交互完全沿用个股数据页；查询框同时支持股票代码与 ETF 代码；查询结果按标的类型互斥渲染。
> 原则：只呈现客观数据，不给出建仓/加减仓/目标价/止损位等任何投资动作建议；派生比率/金额经 `calc/` 或后端归一，前端不手搓公式。
> 状态：**本文只做布局与实现设计，未改动任何代码。**

---

## 一、定位与路由

### 1.1 页面定位

「ETF 数据」= 单只场内 ETF 的**行情、规模、净值、持仓、分红、新闻**客观数据页。它和「个股数据」并列，但**查询后各自独立渲染**：

| 视图 | 数据宇宙 | 内容 |
|---|---|---|
| 个股数据 `/stock-data` | A 股 / 美股 / 港股 | 估值、财报、公司档案、研报、公告、资金面等（现有） |
| ETF 数据 `/etf-data` | 场内 ETF（上市中 + 已退市可查） | 行情、规模/份额、净值/折溢价、持仓、分红、新闻 |

### 1.2 路由与相互跳转

- 新路由 `/etf-data?code=510300`，侧边栏「ETF 数据」放在「个股数据」正下方。
- **共用查询链接**：`/stock-data?code=<ETF代码>` 进入后自动 `replace` 跳转到 `/etf-data?code=<ETF代码>`；`/etf-data?code=<股票代码>` 反向跳回 `/stock-data`。保证历史链接、筛选页链接、自选页链接都能落到正确视图。
- 两个页面共用同一个查询框组件与建议下拉；输入什么类型的代码，就跳到对应页面。
- 进入页面后只请求本视图需要的接口；ETF 视图不请求估值/财报/公司档案等股票接口，股票视图也不请求 ETF 专属接口。

### 1.3 本期不做

- ETF 实时 IOPV / 盘中折溢价（无零鉴权可靠源；仅做 T-1 收盘价/净值口径）。
- ETF 期权链（50ETF / 300ETF / 500ETF / 科创50ETF 的 T 型报价，属独立专题）。
- ETF 成分股穿透到个股页的联动、历史持仓对比。
- 任何「高估/低估/值得买」判断。

## 二、查询框与标的识别

### 2.1 输入框

沿用 `StockCodeInput`，只改占位文案与建议数据源：

```
[ 代码或名称：600519 / 510300 / 沪深300ETF / 00700 / AAPL ]  [ 查询 ]
```

- 支持：A 股 6 位代码、ETF 6 位代码（可带 `.SH` / `.SZ`）、中文简称模糊搜索、港股/美股代码。
- 输入英文/字母 → 走现有美股/港股链路；纯 6 位数字需先判断是否为 ETF。

### 2.2 识别顺序（必须确定，避免错票）

1. **精确 ETF 代码**：查本地 ETF 表（`etf_codes.ts`，由 `etf_basic` 离线生成）；命中 → `/etf-data`。
2. **精确 A 股代码**：查现有 `STOCK_CODES`；命中 → `/stock-data`。
3. **名称/前缀模糊**：合并股票与 ETF 建议列表，按类型标注后让用户选择。
4. 都没命中 → 视为海外代码，走现有 global 链路；仍失败则提示「未找到该代码」。

- 归一化：`510300.SH` → `510300`；ETF 代码允许 5/6 位带后缀，不靠前缀范围硬猜交易所（以 ETF 表为准）。
- 已退市 ETF（`list_status=D`）允许查询，页头加「已退市」灰标，行情/规模显示「—」并说明。

### 2.3 建议下拉

```
┌──────────────────────────────────────────────┐
│ 510300  沪深300ETF          [ETF] 沪市        │
│         跟踪 沪深300指数 · 华泰柏瑞基金        │
├──────────────────────────────────────────────┤
│ 510310  沪深300ETF易方达    [ETF] 沪市        │
│ 600519  贵州茅台            [A股] 主板        │
│ 00700   腾讯控股            [港股]            │
│ AAPL    苹果                [美股]            │
└──────────────────────────────────────────────┘
```

- 每条展示：代码、简称、类型标签（ETF / A 股 / 港股 / 美股）、交易所；ETF 额外一行「跟踪指数 · 管理人」。
- ETF 与股票同名时并列展示，不自动替用户选；回车默认选第一条。
- 数字输入时按 code 前缀匹配；中文按名称包含匹配；ETF 与股票建议合并后统一去重。

## 四、子功能详解

| 区块 | 子功能 | 展示内容与交互 | 布局 | 显示条件 |
|------|--------|----------------|------|----------|
| [A] | 页头 | 标题「ETF 数据」、副标题；有结果时出现「让 AI 读这些数据」 | 标题左、动作右 | 始终 |
| [B] | 查询框 | 股票/ETF 代码或名称；模糊下拉带类型标签；回车/选中即查询 | 输入框 + 按钮 | 始终 |
| [C] | 数据状态条 | 汇总本次失败/暂无数据的块，含来源、错误、重试 | 顶部警示条 | 有失败时 |
| [D] | 空态 | 未查询时的引导文案（支持 ETF 代码与名称） | 居中卡片 | 未查询时 |
| [E] | ETF 概览卡 | 名称/代码/标签、跟踪指数、管理人；8 格指标（最新价、涨跌幅、成交额、换手率、规模、份额、折溢价、管理费率）；OHLC/昨收/成交量副行；三个数据时点 | 8 格 2/4 列 + 副行 | 查到结果 |
| [F] | 基本档案 | 全称、跟踪指数（名称+代码）、基金类型、投资通道、管理人、托管人、成立日、上市日、管理费率、交易所、存续状态 | 8–12 格，2/4 列 | 有静态资料 |
| [G] | K 线 | 日 K 前复权 + MA5/10/20 + 成交量；悬停看当日 OHLC/涨跌/量；默认 250 日（区间切换后续再加） | 全宽自适应 | 有 K 线数据 |
| [H] | 规模与份额 | 两个单指标折线（总规模亿元 / 总份额亿份），共享 X 轴；1年/3年/全部 | 上下两个图 | 有历史规模 |
| [I] | 净值与折溢价 | 单位净值与收盘价双线；折溢价率（收盘价 ÷ 净值 − 1）独立图；1年/3年/全部 | 双线图 + 折溢价图 | 有净值与收盘价 |
| [J] | 前十大持仓 | 最新季报 Top 10：代码、名称、持仓市值、持股数、占股票市值比；显示报告期、披露日、总持仓数；季报滞后提示 | 表格 | 有股票持仓 |
| [K] | 分红记录 | 除息日、每份分红、权益登记日、派息日、方案进度；最近 10 条 | 表格 | 有分红记录 |
| [L] | 相关新闻 | 时间、来源、标题（跳原文）；分页 15 条 | 列表 + 分页 | 有新闻 |
| [M] | 免责声明 | 合规声明 | 页脚 | 始终 |

### 4.1 [E] 概览卡 · 字段与口径

| 指标 | 来源 | 口径 / 备注 |
|---|---|---|
| 最新价 / 涨跌幅 | 腾讯行情（a-stock-data §1.2） | 实时；无报价时显示「—」 |
| 成交额 | 腾讯行情 | 元 → 亿元；实时 |
| 换手率 | 腾讯行情 | 实时口径（该源对 ETF 直接给出） |
| 规模 | tushare `etf_share_size.total_size` | 万元 → 亿元；**T-1 日终** |
| 份额 | tushare `etf_share_size.total_share` | 万份 → 亿份；T-1 |
| 折溢价 | `etf_share_size.close` 与 `nav` | 经 `calc.growth_rate` 计算；T-1 |
| 管理费率 | tushare `etf_basic.mgt_fee` | 原值即 %/年 |
| 今开/最高/最低/昨收/成交量 | 腾讯行情 | 实时 |

- 概览卡底部固定三行时点：`行情 HH:MM:SS · 规模 YYYY-MM-DD · 净值 YYYY-MM-DD`，任一过期转 `text-warning`。
- 规模、份额、折溢价、费率四个数字全部来自后端，前端只格式化。

### 4.2 [F] 基本档案

| 字段 | 来源 |
|---|---|
| 基金全称 / 简称 / 代码 | `etf_basic.cname / csname / ts_code` |
| 跟踪指数（名称 + 代码） | `etf_basic.index_name / index_code`；缺失显示「无跟踪指数」 |
| 基金类型 | `fund_basic.fund_type`（股票型 / 债券型 / 货币型 / 混合型 / 其他） |
| 投资通道 | `etf_basic.etf_type`（境内 / QDII） |
| 管理人 / 托管人 | `etf_basic.mgr_name / custod_name` |
| 成立日 / 上市日 | `etf_basic.setup_date / list_date` |
| 管理费率 | `etf_basic.mgt_fee` |
| 交易所 / 存续状态 | `etf_basic.exchange / list_status` |

- 静态资料优先读本地 ETF 表（`etf_codes.ts`，`etf_basic` 离线快照），后台可用 tushare 刷新；tushare 不可用时仍能展示静态档案，但页面标注「本地快照 · as_of」。

### 4.3 [G] K 线

- 复用现有 `KLineChart` 与 `/api/kline`（东财，已验证对 ETF 返回正常），默认日 K、前复权、MA5/10/20。
- 默认拉取 250 日；区间切换（120/250/500）列入后续增强。
- 若 ETF K 线失败：整块原位错误卡（来源 + 错误 + 重试），不静默隐藏。
- 备用源：tushare `fund_daily`（不复权），仅在主源失败且配置 token 时启用，并在图上标注「不复权 · tushare」。

### 4.4 [H] 规模与份额

- 数据：`etf_share_size` 按 `ts_code` 拉区间，日期升序。
- 上图：总规模（亿元，`total_size ÷ 10000`）；下图：总份额（亿份，`total_share ÷ 10000`）。
- 两张图共享 X 轴与区间按钮；单指标单轴，避免双 Y 轴误读。
- 只画数据点，不做同比/环比结论；缺失日期断开，不插值。
- 时点：T-1，次日 8:30 更新；QDII 更新更晚，页脚注明。

### 4.5 [I] 净值与折溢价

- 数据：`fund_nav`（`unit_nav`）与 `etf_share_size.close`（或 `fund_daily.close`）按日期 join。
- 上图：单位净值与收盘价两条线（同为 T-1 收盘口径）。
- 下图：折溢价率 `% = (close ÷ nav − 1) × 100`，后端经 `calc.growth_rate` 计算，前端只画。
- 同一日期才计算；nav 缺失的日期跳过，不向前填充。
- 文案固定：「折溢价为收盘价与净值的客观差异，不构成高估/低估判断。」

### 4.6 [J] 前十大持仓

- 数据：`fund_portfolio`，取最新 `end_date` 报告期，按 `stk_mkv_ratio` 降序取前 10。
- 列：排名、代码（`symbol`）、名称（本地股票表 join；查不到显示代码）、持仓市值（`mkv` 元 → 亿元）、持股数（`amount` 股 → 万股）、占股票市值比（`stk_mkv_ratio`，%）。
- 头部显示：报告期、公告日、该期总持仓数；固定提示「基金季报数据，存在披露滞后」。
- 空数据：货币型 / 债券型 / 商品型 ETF 可能没有股票持仓；成功但为空时整块不渲染，状态条记「暂无股票持仓（该类型可能不适用）」。
- 失败：原位错误卡，不影响其他块。

### 4.7 [K] 分红记录

- 数据：`fund_div`，按除息日倒序取最近 10 条。
- 列：除息日、每份分红（`div_cash`，元）、权益登记日、派息日、方案进度。
- 无记录：成功为空时整块不渲染；状态条记「暂无分红记录」。

### 4.8 [L] 相关新闻

- 复用现有 `/api/news`（东财），已验证 ETF 代码可返回相关新闻。
- 列：时间、来源、标题（跳原文）；每页 15 条，复用现有分页组件。
- 空：显示「暂无相关新闻」原位提示，不算失败。

## 五、数据能力盘点（a-stock-data / tushare）

### 5.1 a-stock-data 能提供什么

| 能力 | 接口 / 章节 | 对 ETF 的可用性 | 本页用法 |
|---|---|---|---|
| 实时行情 | §1.2 腾讯 `tencent_quote`（`astock.tencent_quote_batch`） | 可用；已验证 510300 返回价格/涨跌/成交额/换手/OHLC | 概览卡 [E] |
| 日 K 线 | §1.3 东财/腾讯 K 线（现有 `/api/kline`） | 可用；已验证 510300 返回日线 | [G] 主源 |
| 个股/ETF 新闻 | 东财新闻（现有 `/api/news`） | 可用；关键词命中 ETF 代码 | [L] |
| ETF 期权链 | §9 新浪 ETF 期权 | 仅 50/300/500/科创50 等标的 | 本期不做 |
| 静态档案 / 规模 / 净值 / 持仓 / 分红 | — | **不提供** | 走 tushare |

### 5.2 tushare 能提供什么

| 接口 | 内容 | 权限 / 限量 | 本页用法 |
|---|---|---|---|
| `etf_basic` | 代码、简称、全称、跟踪指数、管理人、托管人、费率、通道类型、上市日 | ≥5000 积分；单次 ≤5000 | [F] 档案、代码识别 |
| `fund_basic` | `fund_type`（股票/债券/货币/混合/其他） | 公募基金接口 | [F] 基金类型 |
| `etf_share_size` | 每日总份额（万份）、总规模（万元）、净值、收盘价 | ≥8000 积分；单次 ≤5000；次日 8:30 更新 | [E] 规模/份额/折溢价、[H]、[I] |
| `fund_daily` | 日线 OHLC、涨跌、成交量、成交额 | ≥5000 积分；单次 ≤5000 | [G] 备用源、[I] 收盘价 |
| `fund_nav` | 单位净值、累计净值、复权净值、资产净值 | ≥2000 积分 | [I] 净值线 |
| `fund_adj` | 复权因子 | 常规权限 | [G] 复权备用 |
| `fund_portfolio` | 季度持仓：代码、市值、股数、占比 | ≥5000 积分 | [J] |
| `fund_div` | 分红：除息日、派息日、每份分红 | ≥400 积分 | [K] |
| `etf_index` | 基准指数全称/简称/发布机构 | ≥8000 积分 | [F] 指数补充信息 |
| `rt_etf_k` | ETF 实时日线 | **需单独开通权限**；当前 token 无权限 | 不使用 |
| `fund_share` | 基金规模（份额） | 可用 | 备用（`etf_share_size` 失败时） |
| `fund_manager` / `fund_company` | 基金经理 / 管理人 | 可用 | 本期不做 |

> 结论：本页采用「**a-stock-data 提供实时行情 + K 线 + 新闻；tushare 提供静态档案 + 规模/净值 + 持仓 + 分红**」。实时行情不依赖 token；tushare 相关块缺失时按 §六 显式降级。

## 六、数据与降级

### 6.1 状态模型

每个数据块独立维护 `loading / ok / empty / error` 四态，互不阻塞：

| 块 | 主源 | 备用 / 降级 |
|---|---|---|
| 查询识别 | 本地 ETF 表 + `STOCK_CODES` | 本地表缺失 → 用 tushare `etf_basic` 实时查一次 |
| [E] 行情 | 腾讯 | 腾讯失败 → 显示错误，但档案/规模照常 |
| [E] 规模/份额/折溢价 | tushare `etf_share_size` | `fund_share` 仅补份额；规模不可自行估算 |
| [F] 档案 | 本地 ETF 快照 | tushare `etf_basic` 刷新 |
| [G] K 线 | 东财 `/api/kline` | tushare `fund_daily`（不复权，需 token） |
| [H] 规模历史 | `etf_share_size` | `fund_share`（仅有份额，规模缺失时只能画份额） |
| [I] 净值/折溢价 | `fund_nav` + `etf_share_size.close` | `fund_daily.close` 补收盘价 |
| [J] 持仓 | `fund_portfolio` | 无备用；空/失败显式提示 |
| [K] 分红 | `fund_div` | 无备用 |
| [L] 新闻 | 东财 `/api/news` | 无备用 |

### 6.2 失败与缺失必须出声

- 页面顶部「数据状态条」汇总失败/缺失块（来源、错误、重试）。
- 失败块原位显示「⚠ 数据获取失败（来源：xxx · 错误）」；有数据的块照常显示。
- 成功但为空的数据（如无新闻、无分红）显示「暂无数据」，不冒充失败。
- **未配置 `TUSHARE_TOKEN`**：行情、K 线、新闻、本地档案可用；规模/净值/持仓/分红显示「未获取 · 需配置 TUSHARE_TOKEN」，不填 0、不用旧值冒充。
- tushare 积分/权限不足：显示接口原始错误摘要与所需积分，不重试到超时。
- QDII：净值更新可能晚于境内 ETF，净值图与折溢价按 `nav_date` 标注，不把缺失日补 0。

### 6.3 口径纪律

- 规模 `total_size`（万元）→ 亿元、份额 `total_share`（万份）→ 亿份，只在后端换算。
- 折溢价必须同一日期 `close` 与 `nav`；跨期不计算。
- 换手率取腾讯实时口径；历史换手率不混用 T-1 份额重算。
- `fund_portfolio` 的 `stk_mkv_ratio` 字段含义是「占股票市值比」，列名不得写成「占净值比」。
- 涨红跌绿；缺失值统一「—」；金额保留 2 位小数、价格 3 位小数。

## 七、接口设计

### 7.1 复用现有接口（已验证 ETF 可用）

| 接口 | 用途 |
|---|---|
| `GET /api/quote?codes=510300` | 实时行情（腾讯） |
| `GET /api/kline?code=510300&category=4&offset=250` | 日 K（东财） |
| `GET /api/news?code=510300&limit=15&page=1` | 相关新闻（东财） |

### 7.2 新增 ETF 专属接口

```
GET /api/etf/profile?code=510300
GET /api/etf/size?code=510300&range=1y|3y|all
GET /api/etf/nav?code=510300&range=1y|3y|all
GET /api/etf/holdings?code=510300
GET /api/etf/dividends?code=510300
```

| 接口 | 返回要点 |
|---|---|
| `profile` | `code, ts_code, name, full_name, exchange, index_code, index_name, fund_type, etf_type, is_qdii, mgr_name, custod_name, mgt_fee, setup_date, list_date, list_status, source, as_of` |
| `size` | `{code, items:[{date, size_yi, share_yi}], source:"tushare", as_of}`；缺失日期不补点 |
| `nav` | `{code, items:[{date, unit_nav, close, premium_pct}], source, as_of}`；`premium_pct` 由 `calc.growth_rate` 计算 |
| `holdings` | `{code, period, ann_date, total_count, items:[{symbol, name, mkv_yi, amount_wan, ratio_pct}]}` |
| `dividends` | `{code, items:[{ex_date, record_date, pay_date, div_cash, div_proc}]}` |

- 所有接口 `code` 参数接受 6 位代码或 `510300.SH`；后端归一化为 `ts_code`。
- 错误码：无 token → 503（正文含 `TUSHARE_TOKEN`）；积分/权限不足 → 502（正文含接口原始错误）；无数据 → 200 + 空数组。
- `nav` 的折溢价计算必须两侧同日期；`close` 优先 `etf_share_size.close`，缺失时用 `fund_daily.close`。

## 八、视觉规范（与个股数据页一致）

- 容器、卡片、页头、按钮、间距完全复用：`PageHeader` + `GlassCard` + `Disclaimer` + `AskAiButton`。
- 卡片标题：`text-sm font-semibold` + 左侧 4px 主色图标；来源文字 `text-xs text-muted-foreground/60`。
- 指标格：`rounded-lg bg-muted/30 p-3`，标签小字、数值 `font-mono` 加粗；8 格在桌面 4 列、窄屏 2 列。
- 图表：沿用现有 ECharts 风格（网格线弱、无渐变背景、tooltip 白底）；折线主色暖橙，第二条线用中性灰/蓝，不用红绿表达涨跌。
- 折溢价图：正值为 `danger`、负值为 `success`（仅表达符号，不表达好坏），零轴清晰。
- 表格：沿用现有 `text-sm` + 行悬停 `bg-muted/40`；数字右对齐等宽。
- 标签：ETF / 沪市 / 股票型为中性灰 tag；QDII 加「跨境」tag；「已退市」用 warning 色。
- 状态：加载骨架、错误卡、空态与个股页一致；不引入新色板、新圆角。

## 九、验收清单

1. `/etf-data?code=510300` 能直接渲染 ETF 视图；`/stock-data?code=510300` 自动跳转到 `/etf-data?code=510300`。
2. 查询框同时接受股票与 ETF 代码/名称；建议项带类型标签；输入股票代码会跳到 `/stock-data`。
3. ETF 视图与股票视图互斥：ETF 页不请求估值/财报/公司档案，股票页不请求 ETF 专属接口。
4. 概览卡展示 8 项指标与三行数据时点；规模/份额/折溢价均标注 T-1。
5. K 线、规模/份额、净值/折溢价、持仓、分红、新闻各自独立加载；失败/缺失在状态条与原位同时可见。
6. 未配置 `TUSHARE_TOKEN` 时，行情/K 线/新闻/本地档案仍可用；ETF 专属块显示明确原因，不填 0、不静默隐藏。
7. 持仓表列名为「占股票市值比」；分红单位「元/份」；折溢价只做事实陈述。
8. 全页无建仓/加减仓/目标价/止损位等投资动作建议。
9. 视觉与 `/stock-data` 一致：同一卡片、字体、间距、涨跌配色与免责声明。
