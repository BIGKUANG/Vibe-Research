# 个股数据页（/stock-data）数据扩充建议

> 范围：旧版 Web 应用个股数据页 `frontend/src/pages/StockData.tsx`（运行于 `http://localhost:8901/stock-data`）。
> 数据来源参考：`a-stock-data/SKILL.md`（A股全栈数据工具包 v3.6.1，十层 47 端点）。
> 原则：页面只呈现客观公开数据，不给出建仓/加减仓/目标价/止损位等投资动作建议。
> 状态：本文为改造建议，未改动任何代码。

### 1.3 已有数据能力但页面未用到

后端已注册接口、但前端 `api.ts` 未声明或页面未调用的：

| 后端接口 | 返回 | 现状 |
|----------|------|------|
| `GET /api/quote` | 换手率、涨跌停价、昨收、振幅 | 页面未调用（估值卡只用 valuation，没有换手/涨跌停/振幅） |
| `GET /api/info` | 行业、总股本、流通股、上市日期 | 已注册，前端无 `api.info()` |
| `GET /api/finance` | mootdx 季报快照 37 字段 | 已注册，前端无 `api.finance()` |
| `GET /api/announcements` | 东财公告（与巨潮互补） | 已注册，前端无方法 |
| `GET /api/industry` | 行业板块涨跌排名 | 已注册，仅大盘/行业页用，个股页未联动 |

结论：**存在"后端已备好、只差前端展示"的零成本增量**，应在扩充时优先落地。

## 三、展示位置设计（插入点）

以 A 股视图现有渲染顺序为准，给出每个新块的落位。原则：**信息按"我是谁 → 现在什么价 → 经营怎么样 → 市场怎么看 → 资金在干什么 → 有什么风险"由浅入深**。

### 位置 A：估值快照卡内扩展（第 3 区块）

- 在现有 8 个指标块中追加 **换手率、振幅、涨停价/跌停价、52 周高低**（来自 `/api/quote`）。
- 估值卡下方新增一行**公司档案 chips**：行业、上市日期、总股本、流通股本、流通市值。
- 理由：这些是与"现价/市值"同层的高频盘口事实，放同一屏减少滚动。

### 位置 B：K线图区（第 4 区块，增强而非新增）

- `KLineChart` 头部加**周期切换**（日/周/月/60分，对应 `category` 4/5/6/11）。
- K 线右侧/下方加**五档盘口 + 逐笔成交**小面板（mootdx），非交易时段显示"非交易时段，暂无盘口"。
- 理由：盘口与 K 线同源同时点，是最自然的组合。

### 位置 C：估值卡与 K 线之间，新增"公司概况"卡

- 内容：来自 F10「公司概况」+ `/api/info`（主营、行业、上市日期、股本结构摘要）。
- 理由：在进入行情细节前先回答"这家公司是谁"，也是不可替代性判断的入口。

### 位置 D：财报区（第 8 区块，升级为多 tab）

- 将「财务关键指标」卡改为 tab：**摘要指标 / 利润表 / 资产负债表 / 现金流量表**。
- 摘要沿用同花顺；三表走新浪（§6.4），展现最近 5–8 期 + 同比，负值可用绿色标注（沿用现有现金流表惯例）。
- 「财报速览」卡（第 5 区块）下方追加**一致预期明细**：各财年 EPS、覆盖机构数、区间 min/max。

### 位置 E：板块归属·概念卡内扩展（第 15 区块）

- 在概念标签下追加**所属板块资金流向**：该股所属行业/概念的主力净额（今日/5日/10日）及占比。
- 追加**行业排名**（`/api/industry`）：所处行业当日涨跌排名与涨跌家数。
- 理由：已有"板块归属"，补资金与排名即形成"归属 → 强弱 → 资金"闭环。

### 位置 F：资金面·筹码卡内扩展（第 12 区块）

- 增加 **北向资金净流入**（hgt 分钟/日）与 **板块级资金** 摘要行。
- 增加 **资金流四档结构**（超大/大/中/小单），现有仅"近20日主力净流入"单值。

### 位置 G：龙虎榜附近，新增"短线情绪与风险"卡

- 上段：涨停/连板/炸板率等（§8.1–8.3），标注"情绪参考，不进核心结论"。
- 下段：重点监控池 / 日内严重异动（§8.4–8.5），以警示色呈现。
- 理由：龙虎榜本身就是短线资金行为，把打板与风险监控放在一起成组。

### 位置 H：个股新闻旁，新增"快讯"卡

- 财联社电报 + 东财 7×24（§5.2–5.3），可与个股新闻并列或做 tab。
- 理由：个股新闻偏长尾，快讯偏时效，二者互补。

### 位置 I：美/港股视图对齐

- 行情卡追加换手率、涨跌停（如源支持）、52 周高低。
- 财务区追加资产负债表/利润表（目前港股仅现金流量表），使三表齐全。

## 四、实施路径与注意事项

### 4.1 代码落地约定（沿用仓库惯例）

1. 在 `backend/astock.py` **自包含移植**新端点函数（直接 urllib/requests，不依赖 a-stock-data pip 包；复用 `em_get` 限流、`DependencyMissing` 惰性依赖、返回 `list[dict]`）。
2. 在 `backend/app.py` 注册 `/api/*` 路由（含 `_validate` 与错误处理；东财类数据加 30 分钟缓存）。
3. 在 `frontend/src/lib/api.ts` 增加类型与方法。
4. 在 `frontend/src/pages/StockData.tsx` 按上文插入点接入，保持"独立回填、不阻塞主数据"的现有模式与竞态守卫 `runIdRef`。

### 4.2 纪律与降级

- **零鉴权优先**：新增源全部走腾讯/东财/新浪/mootdx；来自 `a-stock-data` 登记端点，不自造爬虫。
- **不动用密钥类源**：iwencai（§2.3）需 Key，暂不纳入页面。
- **合规**：打板情绪、估值分位、资金流一律只作客观呈现，不出现买卖动作建议；情绪类数据需显式标注"情绪参考"。
- **降级出声**：非交易时段盘口为空、老号段僵尸报价（`is_stale`）、东财限流失败，均需在卡片内提示，不静默、不用旧值冒充。
- **计算口径**：新增任何比率/倍数（如资金净占比再加工、同比）必须走 `calc/`，禁止前端手搓公式。
- **双源互校**：公告同时有巨潮与东财源时，冲突需显式列出各源值，不静默取舍。

### 4.3 建议排期

| 批次 | 内容 | 成本 |
|------|------|------|
| 第一批 | 位置 A/B（`/api/quote`）、位置 C（`/api/info`）、财务 tab 摘要补充（`/api/finance`）、公告双源 | 低（仅前端 + api.ts） |
| 第二批 | 位置 C/D（F10 概况、新浪三表）、位置 E/F（板块与资金流）、一致预期明细 | 中（需新增 astock 函数） |
| 第三批 | 位置 B（五档/逐笔/多周期）、位置 G（打板与风险）、位置 H（快讯） | 中高（多源 + 降级处理） |

## 五、一页速览

- **页面已覆盖**：行情估值、K线、估值分位、财务摘要、研报、公告、新闻、资金筹码、龙虎榜、解禁、板块概念、互动易（A股）；行情/财务/现金流（美港股）。
- **最该补且最省事的**：换手率/振幅/涨跌停/公司档案/股本快照/公告双源——后端已注册，只差前端。
- **最该补的高价值项**：公司概况（F10）、财报三表、板块资金流向、一致预期明细、盘口与逐笔。
- **补位原则**：按"我是谁 → 什么价 → 经营如何 → 市场怎么看 → 资金在干什么 → 有什么风险"落位，避免把市场级数据塞进个股页。
