# 上海市人民政府关于由中国（上海）自由贸易试验区临港新片区管理委员会集中行使一批行政权力事项的决定

**沪府发〔2026〕18号**

## 一、决定正文

上海市人民政府关于由中国(上海)自由贸易试验区临港新片区管理委员会集中行使一批行政权力事项的决定各区人民政府,市政府各委、办、局,各有关单位:为进一步支持中国(上海)自由贸易试验区临港新片区(以下简称“临港新片区”)深化高水平改革开放、激发高质量发展强劲动力,根据«中国(上海)自由贸易试验区临港新片区总体方案»«中国(上海)自由贸易试验区条例»«中国(上海)自由贸易试验区临港新片区条例»,市政府决定,由中国(上海)自由贸易试验区临港新片区管理委员会(以下简称“临港新片区管委会”)集中行使1149项行政权力事项,其中,市级事项552项,区级事项597项(包含«上海市人民政府关于收回一批街道办事处乡镇人民政府行政执法事项的通知»(沪府发〔2025〕7号)收回的南汇新城镇执法事项79项).

如无特殊说明,集中行使的行政权力事项实施范围为临港新片区产城融合区.

后续,因法律法规规章调整,需要对临港新片区管委会集中行使事项进行名称变更、拆分合并等调整的,按照权责清单动态管理相关规定执行.

自本决定发布之日起到2026年12月31日,市有关部门、相关区政府和临港新片区管委会要完成相关事项的交接工作,进一步细化明确事项的具体内容、实施范围、监管责任等,及时调整并依法公开办事指南,完善工作衔接机制和区域联动机制,确保接得住、管得好.

市、区相关部门要加强业务指导,一体落实业务系统迭代对接、审批与监管数据双向共享、专业技术常态化支撑等配套保障举措,为临港新片区管委会开展工作提供便利;

要跟踪评估集中行使事项的运行情况,及时梳理总结经验成效,研究解决实施过程中出现的问题.

临港新片区管委会要配齐配强力量,加快转变政府职能,持续深化“一网通办”改革,进一步规范审批行为、优化办事流程,为企业和群众提供高效便捷服务.

采取有力措施,落实监管责任,健全监管规则,创新监管方式,提高监管效能,持续提升企业和群众的满意度、获得感,推动经济社会高质量发展.

2020年1月23日印发的«上海市人民政府关于由中国(上海)自由贸易试验区临港新片区管理委员会集中行使一批行政审批和行政处罚等事项的决定»(沪府规〔2020〕2号)、2020年8月7日印发的«上海市人民政府关于由中国(上海)自由贸易试验区临港新片区管理委员会再集中行使一批行政审批和行政处罚等事项的决定»(沪府规〔2020〕18号)、2022年8月9日印发的«上海市人民政府关于调整由中国(上海)自由贸易试验区临港新片区管理委员会集中行使的行政审批和行政处罚等事项目录的决定»(沪府规〔2022〕8号)同时废止.

附件:1．临港新片区管委会集中行使的市级行政权力事项目录(552项)2．临港新片区管委会集中行使的区级行政权力事项目录(597项)2026年9月15日(此件公开发布)抄送:市委各部门,市人大常委会办公厅,市政协办公厅,市纪委监委,市高院,市检察院.
